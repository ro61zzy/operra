# Operra

AI-powered operations and support platform for modern teams.

Operra helps businesses manage operational workflows, support incidents, internal collaboration, and AI-assisted decision-making in one unified workspace.

## Features

- Multi-tenant workspace architecture
- Ticket & incident management
- AI-powered ticket summarization
- AI knowledge base search
- Operational analytics dashboard
- Team collaboration & notifications
- Authentication & role-based access control
- Real-time updates
- Subscription billing

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM

### AI
- OpenAI API
- Retrieval-Augmented Generation (RAG)

## Monorepo Structure

```txt
apps/

  eslint-config/
```
